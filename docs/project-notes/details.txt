Overall Purpose Summary
=======================
This is a Flutter-based mobile application for plant disease detection. The app leverages AI (using TensorFlow Lite models) to analyze plant images captured via the device's camera or selected from the gallery. It identifies diseases across 51 classes, provides cures in English and Nepali, and includes features like onboarding, notifications, local storage, and multi-language support. The main modules include camera integration, image processing, AI inference, user interface screens, state management, and data persistence.
